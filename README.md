#  Product Review Sentiment Analysis Using Transformers

## 📌 Overview

An NLP-based project that analyzes customer product reviews and classifies them as *Positive, Neutral, or Negative* using Transformer embeddings and Machine Learning.

## 🎯 Objective

To automatically understand customer feedback and identify the sentiment behind product reviews.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn
- Sentence Transformers
- Machine Learning

## 🔄 Project Workflow

Customer Reviews  
↓  
Data Cleaning  
↓  
Exploratory Data Analysis  
↓  
Transformer Embeddings  
↓  
Train-Test Split  
↓  
Model Training  
↓  
Model Evaluation  
↓  
Sentiment Prediction

## 🤖 Models Used

- Random Forest + Transformer
- Gradient Boosting + Transformer

## 📊 Results

| Model | Test Accuracy | Test F1-Score |
|---|---:|---:|
| Random Forest + Transformer | 86.6% | 81.8% |
| Gradient Boosting + Transformer | 84.1% | 80.3% |

Based on the evaluation, *Random Forest + Transformer* was selected as the final model.

## 📈 Output

The system predicts the sentiment of a customer review as:

- 🟢 Positive
- 🟡 Neutral
- 🔴 Negative

## 👩‍💻 Project Outcome

This project provided practical experience in *NLP, Transformer embeddings, Machine Learning, data preprocessing, EDA, and model evaluation*.
